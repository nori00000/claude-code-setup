이 자료는 tmux와 yazi를 처음 배우는 사람을 위한 교육용 HTML입니다. 설치부터 사용법, 자주 나는 오류, 수업 활동, 용어까지 한 번에 따라갈 수 있게 구성했습니다.

tmux 터미널 안에 여러 작업 공간을 만드는 도구입니다. 서버, 편집, 로그 확인을 한 화면에서 관리합니다.
yazi 키보드로 빠르게 움직이는 파일 탐색기입니다. 폴더 이동, 복사, 붙여넣기를 터미널 안에서 처리합니다.
WSL Windows 안에서 Linux를 쓰게 해주는 환경입니다. Windows에서도 tmux를 현실적으로 쓰는 핵심입니다.

1. 왜 필요한가

초보자는 보통 창을 많이 열다가 길을 잃습니다. tmux와 yazi는 “내가 지금 어디서 무엇을 하는지”를 보이게 만드는 도구입니다.

작업을 잃어버리지 않는다

터미널을 닫아도 tmux 세션은 남길 수 있습니다. 나중에 다시 붙으면 하던 작업을 이어갈 수 있습니다.

여러 일을 한 화면에서 본다

왼쪽에는 명령어, 오른쪽에는 파일 탐색기, 아래에는 서버 로그를 둘 수 있습니다.

AI 코딩 도구와 잘 맞는다

AI에게 명령을 맡기고, 다른 pane에서 결과를 확인하고, yazi로 파일을 찾아보는 흐름이 자연스럽습니다.

2. 하지 말아야 할 것

초보자 수업에서는 금지 규칙이 친절함입니다. 아래 규칙은 실수를 줄이기 위한 안전벨트입니다.

Windows PowerShell에서 tmux를 억지로 쓰지 않기

tmux는 Linux 터미널 문화권의 도구입니다. Windows에서는 WSL Ubuntu 안에서 쓰는 것이 안정적입니다.

명령어를 뜻도 모르고 한 줄 복붙하지 않기

특히 sudo, 삭제 명령, 설치 스크립트는 무엇을 하는지 설명을 듣고 실행합니다.

pane을 너무 많이 쪼개지 않기

처음에는 한 window에 pane 2개만 씁니다. 많아지면 오히려 길을 잃습니다.

설정 파일을 백업 없이 덮어쓰지 않기

기존 ~/.tmux.conf가 있다면 먼저 백업합니다. 제공된 스크립트는 자동 백업을 합니다.

오류 메시지를 읽기 전에 다시 실행하지 않기

오류는 힌트입니다. “not found”, “permission”, “network” 같은 단어를 먼저 찾습니다.

AI에게 모든 것을 맡기고 확인하지 않기

AI가 명령을 제안해도, 실행 전에는 대상 폴더와 위험한 명령인지 확인합니다.

3. 설치: 재부팅 후 따라 하기

현재 준비된 설치 스크립트는 C:\Users\1\tmux-yazi-wsl-setup에 있습니다. 재부팅 후 아래 순서대로 진행합니다.

PowerShell에서 WSL 확인

wsl --list --verbose

Ubuntu가 보이면 다음 단계로 갑니다. 안 보이면 아래를 실행합니다.

wsl --install Ubuntu

Ubuntu 실행

wsl -d Ubuntu

처음 실행이면 사용자 이름과 비밀번호를 만듭니다. 비밀번호를 칠 때 화면에 안 보여도 정상입니다.

설치 스크립트 복사 및 실행

cp /mnt/c/Users/1/tmux-yazi-wsl-setup/setup-tmux-yazi.sh ~/
chmod +x ~/setup-tmux-yazi.sh
~/setup-tmux-yazi.sh

설치 확인

tmux -V
yazi --version

첫 세션 시작

tmux new -s main
주의

설치 중 sudo 비밀번호를 묻습니다. Ubuntu 사용자 비밀번호를 입력하세요. 입력 중 글자가 보이지 않는 것은 정상입니다.

4. tmux 기본 사용법

tmux는 session, window, pane 세 단어만 이해하면 절반은 배운 것입니다.

개념 쉬운 비유 예시
Session 책상 하나 main, openplaud, school
Window 책상 위의 노트 한 권 서버용 window, 편집용 window, 파일용 window
Pane 노트를 반으로 접은 칸 왼쪽 명령어, 오른쪽 yazi, 아래 로그

Prefix

tmux에게 “이제 tmux 명령을 할 거야”라고 알려주는 키입니다.

이 설정의 Prefix는 Ctrl + Space 입니다.

예: 새 window 만들기 = Ctrl + Space 누르고 손 떼기, 그 다음 c

처음 외울 키 8개

Prefix + c새 window
Prefix + n다음 window
Prefix + p이전 window
Prefix + %좌우 분할
Prefix + "위아래 분할
Alt+h/j/k/lpane 이동
Prefix + Tabyazi 열기
Prefix + r설정 다시 읽기

5. Yazi 사용법

yazi는 터미널 안의 빠른 파일 탐색기입니다. 마우스 대신 키보드로 폴더와 파일을 움직입니다.

이동

j 아래, k 위

h 상위 폴더, l 폴더 진입

Enter 열기

파일 작업

Space 선택

y 복사, x 잘라내기

p 붙여넣기

종료

q yazi 종료

tmux split 안에서 열었다면 pane만 닫히고 session은 남습니다.

6. 오류 대응법

오류는 실패가 아니라 컴퓨터가 보내는 짧은 편지입니다. 핵심 단어를 찾으면 대부분 해결됩니다.

증상 뜻 해결
wsl: distro not found Ubuntu 배포판이 아직 설치되지 않음 wsl --install Ubuntu 실행 후 재부팅
tmux: command not found tmux가 설치되지 않음 설치 스크립트를 다시 실행하거나 sudo apt install tmux
yazi: command not found yazi 설치가 실패했거나 PATH 문제 which yazi 확인, 설치 스크립트 재실행
복사가 Windows에 붙지 않음 clip.exe 연동 문제 WSL에서 echo test | clip.exe 후 Windows 메모장에 붙여넣기 확인
화면이 깨지거나 색이 이상함 터미널 색상/폰트 문제 Windows Terminal 사용, Ubuntu 탭에서 실행
pane이 너무 많아 헷갈림 도구를 과하게 사용 중 처음에는 window 2개, pane 2개까지만 사용

7. 수업 활동

중학생이나 초보자에게는 설명보다 “작은 성공 경험”이 중요합니다. 아래 활동은 45분 수업 기준입니다.

활동 A: 내 책상 만들기

목표: session, window, pane 구분하기

tmux new -s school
# Prefix + c
# Prefix + %
# Alt+h / Alt+l

활동 B: 파일 찾기

목표: yazi로 폴더 이동하기

cd /mnt/c/Users/1
yazi

활동 C: 오류 읽기

목표: 오류 메시지에서 핵심 단어 찾기

잘못된 명령을 실행해 보고
not found, permission, denied 찾기

8. 효과적인 활용 방안

하나의 정답 대신 3가지 운영 시나리오로 고르게 합니다. 사용자는 자기 수준과 목적에 맞게 고르면 됩니다.

안 1. 학생형

목표: 폴더와 명령어에 익숙해지기

구성: window 1개, pane 2개. 왼쪽 명령어, 오른쪽 yazi.

안 2. 프로젝트형

목표: 개발 서버와 파일을 동시에 보기

구성: window 3개. shell, server, files.

안 3. AI 협업형

목표: AI에게 일을 맡기고 결과를 직접 검토하기

구성: 왼쪽 AI/명령, 오른쪽 yazi, 아래 로그.

운영 원칙

창을 많이 만드는 것이 실력이 아닙니다. “지금 내가 어디서 무엇을 하고 있는지 설명할 수 있는 상태”가 좋은 작업환경입니다.

9. 용어집

낯선 단어를 쉬운 말로 바꾸면 도구가 덜 무섭습니다.

Terminal
글자로 컴퓨터에게 명령하는 창입니다.
Shell
명령어를 해석해서 실행해 주는 프로그램입니다.
WSL
Windows 안에서 Linux를 실행하는 기능입니다.
Ubuntu
많이 쓰이는 Linux 배포판입니다.
tmux
터미널 작업 공간을 나누고 저장하는 도구입니다.
Session
tmux의 가장 큰 작업 단위입니다. 책상 하나라고 생각하면 됩니다.
Window
session 안의 탭입니다.
Pane
window 안에서 나뉜 작은 화면입니다.
Prefix
tmux 명령을 시작한다는 신호 키입니다.
yazi
터미널 안에서 쓰는 파일 탐색기입니다.
PATH
명령어 프로그램을 찾는 위치 목록입니다.
sudo
관리자 권한으로 명령을 실행하겠다는 뜻입니다.
apt
Ubuntu에서 프로그램을 설치하는 도구입니다.
Git
파일 변경 기록을 관리하는 도구입니다.
Clipboard
복사한 내용을 잠시 담아두는 공간입니다.
